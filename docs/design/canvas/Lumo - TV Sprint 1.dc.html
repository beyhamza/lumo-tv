Carte du parcours de focus
Par écran : focus d'arrivée, puis destination de chaque direction depuis chaque zone. Butée = le focus ne bouge pas.
Activation
arrivée → « Actualiser le code »
Élément focusable unique : aucune direction ne bouge le focus (butées partout).
OK régénère le code · Retour quitte l'app.
La validation vient du web : l'écran passe seul à l'Accueil.
Accueil
arrivée → carte 1 du rail « Reprendre »
Onglets : ←→ entre onglets · ↓ rail Reprendre (dernière carte mémorisée) · ↑ butée.
Rail Reprendre : ←→ cartes (butées aux extrémités) · ↑ onglets · ↓ rail Catégories · OK lecture.
Rail Catégories : ←→ cartes · ↑ rail Reprendre · ↓ butée · OK ouvre la grille filtrée.
Retour : écran d'accueil système.
Grille de chaînes
arrivée → dernière chaîne regardée (sinon carte 1)
Filtres : ←→ entre filtres · ↓ grille · ↑ butée.
Grille 4 col. : ←→↑↓ entre cartes · ↑ depuis la ligne 1 → filtres · ← depuis la colonne 1 → butée (l'aperçu n'est pas focusable) · OK lecture.
Une chaîne hors ligne reste focusable : OK affiche l'explication au lieu d'un échec silencieux.
Retour : Accueil.
Lecteur
arrivée → repos, aucun overlay
Repos : OK ouvre l'overlay · ↑↓ chaîne ±1 (zapping direct) · ←→ recule/avance 30 s · Retour → écran précédent.
Overlay (arrivée : Pause) : ←→ entre Pause, Sous-titres, 1080p, Guide (butées) · ↑↓ butées · OK active · Retour ferme.
Auto-masquage après 5 s sans touche ; le focus revient à Pause à la réouverture.
Réglages
arrivée → « Sources » (menu gauche)
Menu : ↑↓ entre les 5 items (butées) · → entre dans le détail (1er élément) · ← butée · OK = →.
Détail : ↑↓ entre les lignes · OK active (bascule, action) · ← retour au menu, position mémorisée · → butée.
Retour : détail → menu, menu → Accueil.
États (erreur, hors ligne, aucune source)
arrivée → bouton primaire
1 bouton : toutes directions en butée · OK agit · Retour sort.
2 boutons : ←→ entre eux, ↑↓ butées · le primaire est toujours à gauche.
Chargement : aucun focus · Retour annule la connexion.
Règle globale : tout écran a exactement 0 ou 1 focus visible ; jamais d'élément atteignable uniquement à la souris.
